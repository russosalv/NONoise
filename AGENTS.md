# AGENTS.md

Instructions for AI agents reading this repository.

- **Installing or updating NONoise in a project** (requests like "update", "aggiorna",
  "install NONoise", "aggiorna le skill"): follow [`UPDATE.md`](UPDATE.md). Run the published
  `create-nonoise` CLI against the user's project; do not clone, build or copy files from this repo.
- **Working on the NONoise monorepo itself** (contributors): follow [`CLAUDE.md`](CLAUDE.md).
